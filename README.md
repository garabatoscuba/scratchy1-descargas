# scratchy1 · descargas

Los instaladores de **scratchy1**, para descargarlos y para que las apps se
actualicen solas. Aquí no hay código: solo los instaladores.

- **Windows**: [scratchy1-Setup.exe](https://github.com/garabatoscuba/scratchy1-descargas/releases/download/ultima/scratchy1-Setup.exe) —
  scratchy1 en su ventana, con el puente de WhatsApp dentro. Doble clic e
  instalado. Si Windows avisa («Windows protegió tu PC»): «Más información» →
  «Ejecutar de todas formas».

scratchy1 en la web: https://scratchy1.com
